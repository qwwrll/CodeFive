01

Що виведе цей код?

const numbers = [1, 2, 3];
const result = numbers.map(number => number * 2);

console.log(result);

Обери одну відповідь:

Метод map() створює новий масив із результатів виконання функції для кожного елемента. Тут кожне число множиться на 2: 1 → 2, 2 → 4, 3 → 6. Початковий масив numbers не змінюється.
